02 · GLOWCARD

GlowCard — 1px 渐变描边 + 环境辉光

对应 components/glow-card.tsx：hover 增强辉光（半径 48→64px）；第二张是 tintBorder 染色描边；第三张低强度 intensity .6。

amber · default

默认中性描边 + 琥珀环境光

--glow 决定颜色，--gi 控制强度；描边是 白→边框色 渐变。

teal · tint · gi 1.3

染色描边 tintBorder

描边本身被辉光色染透，顶部亮、向下渐隐。

red · gi .6

低强度 + 虚线头部 chip

风险类卡片用红色低辉光，克制但醒目。

03 · NODEFLOW

NodeFlow — SVG 节点流光

对应 components/node-flow.tsx：edges 画管网、pulses 沿 path 流动（SVG 原生 animateMotion，零依赖）、nodes 画节点。四种常用拓扑：

fan-out → merge
funnel（漏斗过滤）
branch 1→3（三选一）
zigzag（慢速高风险）
04 · THE DIAL + MINUTE LIST

TheDial — 30 段圆角环扇转盘 + 连续分钟时钟

对应 components/the-dial.tsx + minute-list.tsx + hooks/use-minute-clock.ts。 视频动态：指针 7.5s 连续扫一整圈，刻度跟随指针逐段点亮，扫完的区半亮，指针身后有 32° 渐隐光楔； 色点外引线连标签，HUNT 是唯一的贯穿线（only block 04 points outward）。
