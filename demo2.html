02 · GLOWCARD

GlowCard — 1px 渐变描边 + 环境辉光

对应 components/glow-card.tsx：hover 增强辉光（半径 48→64px）；第二张是 tintBorder 染色描边；第三张低强度 intensity .6。

amber · default

默认中性描边 + 琥珀环境光

--glow 决定颜色，--gi 控制强度；描边是 白→边框色 渐变。

teal · tint · gi 1.3

染色描边 tintBorder

描边本身被辉光色染透，顶部亮、向下渐隐。

red · gi .6

低强度 + 虚线头部 chip

风险类卡片用红色低辉光，克制但醒目。

03 · NODEFLOW

NodeFlow — SVG 节点流光

对应 components/node-flow.tsx：edges 画管网、pulses 沿 path 流动（SVG 原生 animateMotion，零依赖）、nodes 画节点。四种常用拓扑：

fan-out → merge
funnel（漏斗过滤）
branch 1→3（三选一）
zigzag（慢速高风险）
04 · THE DIAL + MINUTE LIST

TheDial — 60 刻度转盘 + 共享分钟时钟（视频版式）
