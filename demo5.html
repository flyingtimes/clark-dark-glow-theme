DESIGN TOKENS
clark 的暗黑辉光主题 · 设计公式

· 辉光 = box-shadow 0 0 Npx -Mpx color-mix(in oklab, accent 75%, transparent)
· 描边 = 1px（白10% → border → 透明 渐变 或 accent/45%）
· 焦点 = 边框转 accent + 辉光增强，全站 focus-visible
· 字体 = JetBrains Mono，标签 11px 大写宽字距
· 五色 = amber 主 / violet / teal / red / green，全走 CSS 变量
